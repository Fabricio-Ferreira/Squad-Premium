<h1 align="center"> Squad Premium </h1>

![logodasquadpremium](https://user-images.githubusercontent.com/13634186/232494109-b952c616-4bfc-4253-9b24-f98c60b757b9.png)


O app é gerenciador de tarefas que podem ter dois status, PENDENTE e CONCLUÍDA. Ele apresenta uma lista de tarefa, onde você pode inserir, deletar e editar uma tarefa.
